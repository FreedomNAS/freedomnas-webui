# What the WebUI needs to start. Two of these are not direct imports and are
# the easiest to forget: jinja2 arrives through fastapi.templating, uvicorn is
# how the supervisor launches the app. The distribution packages that
# provide these are named in debian/control, PKGBUILD and the Gentoo ebuild;
# this file is the list they all answer to.
fastapi
uvicorn
jinja2          # fastapi.templating, built at import time in api/main.py
python-pam      # api/deps.py: authentication
PyYAML          # configuration import/export
